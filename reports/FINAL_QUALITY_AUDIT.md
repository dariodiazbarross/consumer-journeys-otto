# Final professional quality audit

## Data Scientist

The question and estimand were frozen before historical signals or scores. Official
time order replaces random splitting; all signal tables use strict pre-period
events; the test target is first introduced after candidates and ranks exist. The
protocol uses one prefix per session, distinct simultaneous target sets, macro
Recall@20, MRR@20 and paired session bootstrap intervals. Validation and test agree
on the direction and approximate size of the contextual lift. A detected closeout
race involving the final three Parquet blocks was fixed and every historical
aggregate was recomputed before evaluation. Full event/session totals reconcile.

## Consumer / Behavioral Scientist

The analysis reports observable exploration breadth, revisits and timestamp-block
action transitions. It does not rename them loyalty, indecision, intention,
impulsivity or irrationality. Mixed simultaneous actions remain mixed. The README,
notebooks and ethics document distinguish description, prediction and causality.

## Recommender Systems / ML Professional

Candidate retrieval and ranking use separate grains and diagnostics. Targets never
enter candidates; popularity, repeat and association baselines are deterministic;
the fixed ablation isolates repetition, associations, then action/recency context.
Candidate recall, top-20 loss, coverage and item-history subgroups identify that
retrieval, especially outside the historical head, deserves more attention than
minor ranking refinements. V1 does not implement the proposed LightGBM extension.

## Technical Recruiter

The first README screen exposes the question, full-data scale, held-out result and
main figure. SQL depth is visible in seven purpose-specific files; Python handles
bounded ingestion, orchestration, paired inference, figures and reporting. Four
executed notebooks provide an accessible review path. CI tests analytical contracts
without downloading raw data.

## Hiring Manager

The case study shows judgement through a strong recent-repeat benchmark, resource
measurement before infrastructure choice, full-data processing on constrained
hardware, honest ablations, error decomposition and explicit business boundaries.
The recommendation is conditional: context adds offline predictive information,
while an online experiment remains necessary for causal or commercial decisions.

## Material limitations retained

One final week, positive-target conditioning, no inventory/product/exposure context,
source-defined sessions, exact duplicate events, hand-set scores and fixed candidate
rules constrain generalization. Bootstrap intervals condition on this fitted system
and observed cohort. These limits are prominent rather than relegated to a footnote.
